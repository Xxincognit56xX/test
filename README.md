## Getting started

### Requirements

- Python 3
- pip

### Setup

1. **Fork** this repository, then clone your fork:
   ```bash
   git clone https://github.com/xXincognit56Xx/test.git
   cd test
   ```
2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
3. **Create your `.env` file:**
   ```bash
   python check_env.py
   ```
   > On Windows you can use `py check_env.py` instead.
4. **Explore** and test out different features.
